# BMI Calculator

A beginner-friendly Python program that calculates Body Mass Index (BMI) based on the user's weight and height.

## Features

- Takes weight in kilograms as input
- Takes height in meters as input
- Calculates BMI using the standard BMI formula
- Displays BMI rounded to 2 decimal places
- Classifies BMI as:
  - Underweight
  - Normal
  - Overweight
  - Obese
- Handles non-numeric input
- Prevents negative weight and invalid height values

## BMI Formula

BMI = Weight (kg) / Height² (m)

## Technologies Used

- Python
- `input()`
- Conditional statements
- Basic arithmetic
- Exception handling
